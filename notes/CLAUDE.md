# notes/ 使用规范（AI 提示词）

> 本文档规范 `notes/` 目录的内容与写作约定。notes/ 下所有文件都是**面向 AI 的提示词/参考**，非面向用户文档。

## 全中文

- **notes/ 下所有内容一律使用中文**（技术术语与英文标识符除外）。
- 这是刻意选择：notes/ 是 AI 协作层的记忆载体，中文表达设计意图更精确；**用户侧（CLI 输出）相反——全英文**（见 decisions.md D8）。

## 目录职责

| 文件 | 职责 |
|------|------|
| `MEMORY.md` | 项目记忆索引（索引入口，先看这里） |
| `DDD.md` | 领域概念词汇表（概念定义、字段、状态机） |
| `roadmap.md` | 版本规划与发布策略 |
| `decisions.md` | 技术选型与决策记录（ADR 式，追加不修改） |
| `CLAUDE.md` | 本规范 |

## 写作约定

- **新增概念**必须登记进 `DDD.md`。
- **技术选型**必须记录进 `decisions.md`（背景 → 决策 → 理由）。
- **新决策追加**，不修改已定条目；推翻需标注。
- 新增 notes 文件后更新 `MEMORY.md` 索引。
- 概念用英文标识符 + 中文解释；状态、命令、表名用代码样式（反引号）。
