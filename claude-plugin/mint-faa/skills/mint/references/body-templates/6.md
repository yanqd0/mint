# T6 plan - execution

**Purpose**: Record an execution plan.

```markdown
## Goal <one sentence>
## Steps
- one line per phase
## Acceptance
- one line per item
```

Split by phase; acceptance verifiable.
**Note**: use plain `- ` lists for steps/acceptance — **no `- [ ]` checkboxes** (the agent does not re-edit the body, so a checkbox would forever show unchecked).
