# milestone title rules

**Semantics**: a large business goal / version direction.

- One sentence expressing business value or version positioning (e.g. `TUI (human viewing)`)
- Version goes to `--version` (e.g. 0.5.0), not the title

**Limit**: ≤60 chars (~30 CJK), compress if longer.

Examples:
- `multi-machine sync + read/write split`
- `deliverable size/perf optimization`
