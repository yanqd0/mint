# issue title rules

**Semantics**: summarize the action/implementation by kind.

- problem → symptom/impact: `login button unresponsive`
- requirement → goal: `implement X feature`
- task → chore/documentation/research/CI: `docs(skill): map flow-todo to task`
- Describe WHAT, not WHY (rationale goes to body or decision record)

**Limit**: ≤60 chars (~30 CJK), compress or move to body if longer.

**A good title can omit body**: skip `--body` when title is self-explanatory.

Examples:
- problem: `list pagination occasionally blanks`
- requirement: `implement full-text search for issues`
- task: `chore: remove dead SQL files`
