# plan title rules

**Semantics**: a larger implementation goal.

- One sentence expressing WHAT to implement (e.g. `mint tui interface refactor`)
- No details/decomposition (goes to body T6/T7)

**Limit**: ≤60 chars (~30 CJK), compress if longer.

Examples:
- `issue dedup + full-text search`
- `multi-machine sync (S3 relay)`
